# ZIP Shrinker — 500 MB target

This GitHub Pages website lets you select a ZIP file and try to recompress its files with maximum DEFLATE compression. Files are processed in your browser and never uploaded to GitHub.

The target is 500,000,000 bytes (500 decimal MB) or less. Already-compressed media and archives may not shrink to the target; the site reports the actual result and provides a download even if it is larger. Exact size cannot be guaranteed without adding padding or changing/removing data.

Large archives may exhaust browser memory. The original ZIP remains unchanged.

Open index.html to use the compressor. PLAYER.html redirects to index.html.
